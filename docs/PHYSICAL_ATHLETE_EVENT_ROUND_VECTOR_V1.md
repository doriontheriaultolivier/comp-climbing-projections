# Physical observations to athlete-event round vectors V1

This descriptive artifact turns the chronological observation-result timeline
into 5,831 observation x athlete-event-context bundles. Exact discipline, pool,
category and source event remain separate. All 10,406 original result rows are
preserved inside structured round vectors; 3,750 bundles contain multiple
rounds.

It deliberately does not select a best round, average ranks across rounds, or
invent an event-level performance score. Those operations would hide format and
survivor-selection differences and would inflate apparent evidence when one
competition publishes more round rows than another.

Coverage is currently 2,751 Boulder, 2,624 Lead and 456 Speed bundles across 20
athletes. This remains descriptive and cannot authorize a model, prediction, or
training prescription.

The next gate is an exact event/item join to reviewed Boulder demand tags.
Untagged events must remain explicitly untagged; tags may not be inferred from
outcomes or athlete identities.
