# Physical and Kilter to later-competition timeline V1

This research artifact replaces the misleading comparison of historical tests
with a current rating. Every row links one dated physical or Kilter observation
to a competition result strictly 1–365 days later through the governed identity
bridge.

Coverage is 613 observations, 20 athletes, 170 later competition fields and
10,406 observation-result pairs. Three joined rows from explicitly quarantined
test events were removed using the governed event taxonomy. Pair rows are not independent observations and
must not be reported as the effective sample size. CEC dominates the current
coverage; source and competition clustering are mandatory.

No model is fit. Missing tests remain missing. No linear relationship, causal
training recommendation, physical ceiling, or competition prediction is
claimed.

The next gate is athlete-event aggregation with no duplicate-round inflation,
followed by reviewed boulder-demand tags. Only then should predeclared monotone
saturating physical-support, Kilter-expression and competition-accessibility
candidates be compared under grouped chronological validation.
